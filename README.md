# Simple Calculator

An offline, dependency-free Flutter Android calculator with a dark, high-contrast interface.

## Run

From this directory:

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

## Build an installable APK

```bash
flutter build apk --release
```

The release APK is written to `build/app/outputs/flutter-apk/app-release.apk`.

The app has no backend, database, network calls, login, or third-party runtime packages.
